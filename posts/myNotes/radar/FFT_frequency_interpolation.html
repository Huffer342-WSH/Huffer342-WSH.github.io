通过拟合计算提高FFT幅度谱求频率的分辨率

2025-07-05
1.3k
9m
信号处理算法

1. 问题描述 ​

当信号为单一频率成分，但其频率不在FFT分辨率点上时，无法直接通过FFT幅度谱峰值点获得精确频率。

在单一信号频率无噪声的情况下，幅度谱的‘形状’只和频率有关，和信号的幅度与相位无关（这里的形状可以指归一化幅度谱）。因此可以尝试通过幅度谱的形状推导出频率。

本文通过数学推导得出幅度谱比值和频率的关系，从而得到频率插值的公式。

python
def fit_func1(x0, x1, x2, y0, y1, y2):
    assert y1 >= y0 and y1 >= y2
    a = x1
    b = -1 if (y0 > y2) else 1
    r = y1 / (y0 if (y0 > y2) else y2)
    x_peak = a + b / (r + 1)
    return x_peak

具体的Python实验：非整数倍周期信号FFT影响.py

该方法的实际应用：idx_estimation()函数：通过中心点的幅度谱值与相邻点的幅度谱值，估计出更精确的坐标

2. 数学模型 ​

2.1 信号定义 ​

考虑归一化频率为 fff 的复指数信号：

x[n]=ej2πfn,n=0,1,⋯ ,N−1x[n] = e^{j2\pi f n}, \quad n=0,1,\cdots,N-1 x[n]=ej2πfn,n=0,1,⋯,N−1

其DFT定义为：

X[k]=∑n=0N−1x[n]e−j2πkn/NX[k] = \sum_{n=0}^{N-1} x[n] e^{-j2\pi kn/N} X[k]=n=0∑N−1​x[n]e−j2πkn/N

2.2 等比数列求和 ​

将信号表达式代入DFT：

X[k]=∑n=0N−1ej2πfn⋅e−j2πkn/N=∑n=0N−1ej2πn(f−k/N)X[k] = \sum_{n=0}^{N-1} e^{j2\pi f n} \cdot e^{-j2\pi kn/N} = \sum_{n=0}^{N-1} e^{j2\pi n (f - k/N)} X[k]=n=0∑N−1​ej2πfn⋅e−j2πkn/N=n=0∑N−1​ej2πn(f−k/N)

这是一个首项为 a1=1a_1 = 1a1​=1，公比为 r=ej2π(f−k/N)r = e^{j2\pi (f - k/N)}r=ej2π(f−k/N) 的等比数列。等比数列求和公式为：

SN=a11−rN1−rS_N = a_1 \frac{1 - r^N}{1 - r} SN​=a1​1−r1−rN​

代入参数：

X[k]=1−[ej2π(f−k/N)]N1−ej2π(f−k/N)X[k] = \frac{1 - [e^{j2\pi (f - k/N)}]^N}{1 - e^{j2\pi (f - k/N)}} X[k]=1−ej2π(f−k/N)1−[ej2π(f−k/N)]N​

2.3 简化表达式 ​

化简分子：

[ej2π(f−k/N)]N=ej2πN(f−k/N)=ej2π(Nf−k)[e^{j2\pi (f - k/N)}]^N = e^{j2\pi N(f - k/N)} = e^{j2\pi (Nf - k)} [ej2π(f−k/N)]N=ej2πN(f−k/N)=ej2π(Nf−k)

由于 kkk 是整数，e−j2πk=1e^{-j2\pi k} = 1e−j2πk=1，所以：

ej2π(Nf−k)=ej2πNfe^{j2\pi (Nf - k)} = e^{j2\pi Nf} ej2π(Nf−k)=ej2πNf

因此分子简化为：

1−ej2πNf1 - e^{j2\pi Nf} 1−ej2πNf

最终DFT表达式为：

X[k]=1−ej2πNf1−ej2π(f−k/N)X[k] = \frac{1 - e^{j2\pi Nf}}{1 - e^{j2\pi (f - k/N)}} X[k]=1−ej2π(f−k/N)1−ej2πNf​

2.4 幅度谱表达式 ​

幅度谱为：

∣X[k]∣=∣1−ej2πNf1−ej2π(f−k/N)∣|X[k]| = \left| \frac{1 - e^{j2\pi Nf}}{1 - e^{j2\pi (f - k/N)}} \right| ∣X[k]∣=​1−ej2π(f−k/N)1−ej2πNf​​

利用复指数性质 ∣1−ejθ∣=2∣sin⁡(θ/2)∣|1 - e^{j\theta}| = 2|\sin(\theta/2)|∣1−ejθ∣=2∣sin(θ/2)∣：

∣X[k]∣=∣sin⁡(πNf)∣∣sin⁡[π(f−k/N)]∣|X[k]| = \frac{|\sin(\pi Nf)|}{|\sin[\pi (f - k/N)]|} ∣X[k]∣=∣sin[π(f−k/N)]∣∣sin(πNf)∣​

3. 任意两点幅度比值计算 ​

3.1 分类讨论 ​

∣X[k]∣|X[k]|∣X[k]∣表达式的分子是一个不随序号kkk改变的值，那么通过相除可以去掉该项

考虑频点 aaa 和 bbb，其幅度比为：

∣X[a]∣∣X[b]∣=∣sin⁡[π(f−a/N)]∣−1∣sin⁡[π(f−b/N)]∣−1=∣sin⁡[π(f−b/N)]∣∣sin⁡[π(f−a/N)]∣\frac{|X[a]|}{|X[b]|} = \frac{|\sin[\pi (f - a/N)]|^{-1}}{|\sin[\pi (f - b/N)]|^{-1}} = \frac{|\sin[\pi (f - b/N)]|}{|\sin[\pi (f - a/N)]|} ∣X[b]∣∣X[a]∣​=∣sin[π(f−b/N)]∣−1∣sin[π(f−a/N)]∣−1​=∣sin[π(f−a/N)]∣∣sin[π(f−b/N)]∣​

当 f−b/Nf-b/Nf−b/N 的值非常小时，可以应用近似：

sin(x)=xsin(x) = x sin(x)=x

因此我们取点峰值点k1k_1k1​与相邻点k1±1k_1 \pm 1k1​±1计算比值

在峰值邻域（k1k_1k1​及其相邻点），设f=k1+δNf = \frac{k_1 + \delta}{N}f=Nk1​+δ​，则：

  1. 峰值点k1k_1k1​：

情况1：δ≥0\delta \geq 0δ≥0(取右侧点k1+1k_1+1k1​+1)

r=∣X[k1]∣∣X[k1−1]∣=∣sin⁡[π(δ+1)/N]∣∣sin⁡(πδ/N)∣≈∣1+δ∣∣δ∣=−1+δδr = \frac{|X[k_1]|}{|X[k_1-1]|} = \frac{|\sin[\pi (\delta + 1)/N]|}{|\sin(\pi \delta/N)|} \approx \frac{|1 + \delta|}{|\delta|} = -\frac{1 + \delta}{\delta} r=∣X[k1​−1]∣∣X[k1​]∣​=∣sin(πδ/N)∣∣sin[π(δ+1)/N]∣​≈∣δ∣∣1+δ∣​=−δ1+δ​

3.2 统一表达式 ​

两种情况的解可统一表示为：

δ≈br+1\delta \approx \frac{b}{r + 1} δ≈r+1b​
